# DSH Opaque Window Test

关闭主窗口原生磨砂效果的 DeepSeek Harness macOS 测试版。

该版本面向 **Intel 芯片 Mac**，目的是通过关闭主窗口的原生磨砂（`vibrancy`）和透明背景、改用实色背景，尝试降低与 `VRR_ERR` 相关的屏幕渲染超时、黑屏以及异常重启或退回登录界面的问题发生概率。**这是用于排查和对照测试的本地修改版，实际缓解效果尚未验证，也未确定 `VRR_ERR` 与上述现象之间的因果关系。**

## 下载

请在本仓库的 **Releases** 页面下载，两个附件包含同一测试版程序，任选一个即可：

- `DSH.Opaque.Window.Test.zip`：现有 ZIP 压缩包，解压后得到 `.app` 程序。
- `DSH-Opaque-Window-Test-macOS-x64.app.tar.gz`：程序目录包的归档，解压后得到同一 `.app` 程序；保留可执行权限与符号链接。

`.app` 在 macOS 中看起来是一个程序文件，实际是目录包，因此需要归档后作为 Release 附件提供。程序本体较大，下载附件放在 Releases 中。

## 主要改动

- 主窗口关闭原生 `vibrancy`，取消透明背景，始终使用实色背景。
- 主窗口显示、恢复及系统主题变化时，保持实色背景。
- 测试范围限于主窗口的原生磨砂与透明合成；欢迎页及其他辅助窗口不属于本次对照范围。
- Electron、前端、内置运行时和 GPU 开关沿用基础版本。
- 使用独立的程序标识与数据目录，不注册正式版的 `dsh://` 链接，也不连接正式版的桌面更新源。

## 使用方法

1. 保存工作，并用 `⌘Q` 完全退出当前运行的正式版或其他测试版；仅关闭窗口并不等同于退出程序。
2. 下载并解压任一 Release 附件，在 Finder 中打开 `DSH Opaque Window Test.app`。
3. 首次启动会使用独立的数据目录，根据需要登录或配置。使用测试工作区进行观察，避免多个实例同时操作同一项目。
4. 正常使用并记录现象。为了便于对照，测试期间保持刷新率、GPU 加速以及 macOS“减少透明度”等其他设置一致。
5. 如再次发生卡顿、黑屏或退回登录界面，记录画面开始冻结的时间、应用切换过程以及实际症状；同时保留系统诊断资料。`VRR_ERR` 日志条数本身不足以判断问题是否缓解。
6. 切回正式版时，先退出测试版，再打开“应用程序”中的 DeepSeek Harness。

## 数据目录

测试版数据位于：

```text
~/Library/Application Support/DSH Opaque Window Test/
```

其中包含独立的 DSH 数据根目录、浏览器缓存及诊断日志。程序不会自动导入正式版的会话、插件、登录信息或设置。

Release 附件同时提供 `SHA256SUMS.txt`。可在下载目录执行：
